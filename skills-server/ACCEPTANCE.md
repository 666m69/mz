### ما اختُبر عند الفشل

- فشل تفعيل إصدار قبل نجاح اختباره. رُفض تمرير `test_status` أو كود أو مسار ملف في طلب التسجيل.
- رفض الخادم رمز طلب آخر، وأصل ويب أجنبيًا، وتغيير الحمولة خلف مفتاح مكرر، ونتيجة مشغّل انتهت مهلته. أوقف التعطيل المهام المنتظرة والجارية، ونجح التراجع إلى الإصدار السابق المختبَر.
- منعت عملية البناء فعلًا فتح الشبكة، وقراءة ملف للنظام، والكتابة خارج دليل المخرجات، وبدء عملية فرعية. أُوقفت مهمة CPU ومهمة تتجاوز الست ثواني. فُحص توقف المشغّل عند فشل تحميل طبقة العزل.
- فشلت فكرة طلبت ربط العدّاد بواتساب ودفع حقيقي بالرمز `technical_review`. ظهر الخطأ للمالك، وظلت محاولة تنزيل ملفها مرفوضة.
- احتفظت إعادة التشغيل بالحالة ومفتاح طلب العميل. تعذّر استبدال مفاتيح مفقودة بقاعدة موجودة. لا تضم سجلات التشغيل نصوص الأفكار أو أسرار العملاء.

## التكلفة والقرار التالي

التكلفة الإضافية لهذا التنفيذ صفر ريال. نُفّذت الاختبارات على الجهاز المتاح واستخدمت قراءة إعدادات Cloudflare وكتابة المصدر في فرع GitHub مستقل. لم يُفعَّل اشتراك أو مورد تشغيل أو بريد أو واجهة تسعير أو دفع. الحصص في التطبيق حدود محلية للتجربة، وليست تقديرًا لفاتورة استضافة مستقبلية.

ما بقي قبل تجربة مستضافة هو التحقق من الحصة وصلاحية النشر لبيئة اختبار مستقلة، ثم تشغيل نفس الاختبارات على Worker وD1 مخصصين لها وربط مشغّل موثوق متاح. لم يُختبر workerd أو D1 المستضاف في هذه الجولة. يلزم قرار المالك قبل وصل نموذج الموقع ببيانات عملاء أو تحديد سعر أو تحصيل دفع أو نشر. لا توجد عملية انتقال بيانات مطلوبة لهذه المرحلة.
